# Achyut Yesare — Personal Portfolio

Personal portfolio website showcasing my work, technical interests, selected projects, and engineering journey across AI/ML, computer vision, edge AI, and software development.

**Live website:** https://achyut0617.github.io/

## Overview

This repository contains the source code for my personal portfolio, built with a lightweight static web architecture.

The website is designed to present my technical background, selected projects, tools and technologies, and areas of exploration in a clean and responsive interface.

## Sections

- **About** — Academic background and engineering interests.
- **Technical Toolkit** — Programming languages, machine learning frameworks, development tools, and systems technologies.
- **Selected Projects** — Applied AI/ML, computer vision, edge AI, and IoT projects.
- **Areas of Exploration** — Current technical interests and learning directions.
- **Contact** — GitHub and LinkedIn profiles.

## Technology Stack

| Area | Technologies |
|---|---|
| Structure | HTML5 |
| Styling | CSS3 |
| Typography | Google Fonts |
| Graphics | Inline SVG |

The website does not require a JavaScript framework, package manager, or build process.

## Run Locally

Clone the repository:

```bash
git clone https://github.com/Achyut0617/Achyut0617.github.io.git
cd Achyut0617.github.io
```

Open `index.html` in your browser.

Alternatively, start a local development server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Deployment

This repository uses GitHub Pages.

To publish updates:

1. Push the updated files to the `main` branch.
2. Open the repository's **Settings → Pages**.
3. Configure the deployment source to use the `main` branch and root directory.
4. Wait for the GitHub Pages deployment to complete.

The website is available at:

https://achyut0617.github.io/
